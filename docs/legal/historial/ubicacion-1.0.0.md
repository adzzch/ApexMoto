# Aviso de uso de la ubicación

**Versión 1.0.0**

ApexMoto usa la ubicación de tu teléfono solo mientras tienes la aplicación abierta y solo para esto:

- **Guiado giro a giro:** seguir tu posición sobre la ruta y recalcularla si te desvías. El punto de partida y el destino se envían al servicio de rutas para calcularla. No guardamos tu recorrido.
- **S.O.S.:** cuando tocas "Usar mi ubicación", guardamos el punto donde estás para que el taller pueda llegar. Lo ven los talleres aliados mientras se busca uno, y después solo el taller que aceptó. Las coordenadas se borran cuando el S.O.S. termina o se cancela.
- **Mapa de comercios:** mostrarte en el mapa. No se guarda.
- **Ubicación de tu negocio:** si eres comercio o taller, fijar dónde queda tu local.

Lo que **no** hacemos:

- No usamos tu ubicación con la aplicación cerrada o en segundo plano.
- No compartimos tu posición en tiempo real con otros usuarios.
- No la usamos para publicidad.

Puedes decir que no: la aplicación sigue funcionando, pero sin guiado en vivo y sin envío automático del punto del S.O.S. (podrás escribir dónde estás). También puedes retirar el permiso después en Ajustes de Android → Aplicaciones → ApexMoto → Permisos.
